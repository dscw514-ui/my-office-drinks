Office Hub V4.0 — 聚餐管理版

部署步驟
1. 先備份 GitHub 專案與 Supabase 資料庫。
2. 在原本 Supabase 專案 SQL Editor 執行 supabase/meal_v4.sql（不要重新執行或清除舊表）。
3. 將 ZIP 解壓後所有檔案覆蓋至原 GitHub Pages repository 根目錄。
4. 等 GitHub Pages 更新後，進入首頁，點右下角「🍽️ 聚餐管理」；或直接開啟 /meal.html。
5. 使用原有飲料管理者密碼載入資料，建立活動、登記與分配額度。

保留功能
- 原飲料 js/app.js、js/backend.js、js/logic.js、Supabase od_shops/od_units/od_sessions/od_orders 均不更動。
- 原團購 ?g= 連結仍由飲料首頁處理。
- 聚餐新表為 od_meal_events、od_meal_registrations、od_meal_allocations、od_meal_audit。
- 人員名單直接使用既有 od_units。

聚餐規則
- 每活動獨立設定額度、成人/兒童餐費、身高門檻。
- 本人算一位成人；眷屬分為達門檻與未達門檻兩類。
- 可選本人或未參加聚餐同事作額度提供者；每人每活動額度有上限。
- 多筆登記額度在資料庫交易中檢查，活動列鎖可避免同時重複使用。
- 修改登記時重新分配額度；刪除登記自動返還。
- 管理者需取得額度提供者同意後儲存。
- CSV 可輸出登記及額度來源。

注意
- 這是管理者代登記版：為保護個資，聚餐名單及額度資料需管理密碼才能讀取/寫入。
- 聚餐功能目前為獨立 meal.html 頁面，由飲料首頁的「聚餐管理」入口切換。
- 未實際連線到你的 Supabase 執行 SQL，也未完成正式環境端到端測試。
- 建議先用測試活動驗證額度借用、多人同時登記、修改/刪除、截止與 CSV，再正式使用。
