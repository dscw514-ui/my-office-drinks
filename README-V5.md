# Office Hub V5 — 聚餐介面整合

## 更新重點
- 聚餐分頁固定為與飲料頁一致的四個：訂購、彙總、菜單、名單（同順序）。
- 開團清單／建立新團移到訂購頁的按鈕展開區，不再多一個分頁。
- 人員名單仍共用原飲料系統的 `od_units`，不複製資料。
- 聚餐菜單新增「允許借用其他同事額度（包含未參加者）」勾選，寫入餐廳規則，並在前端與資料庫驗證。
- 既有聚餐活動仍各自設定額度；額度不能重複使用的交易驗證保留。

## 部署
1. 備份現有 GitHub 及 Supabase 資料庫。
2. 若先前已執行 V4.0 和 V4.1 SQL，只執行 `supabase/meal_v5_upgrade.sql`。請勿重跑 `setup.sql`。
3. 將 ZIP 中前端檔案覆蓋 GitHub Pages 專案；`supabase` 資料夾不必上傳到公開網頁。
4. 重新整理後測試：四分頁切換、開團、菜單儲存借用規則、登記額度及彙總。

## 注意
此版保留原飲料頁的 JavaScript 與資料庫，聚餐仍使用 `meal.html`，並非同一個 JS 元件。按鈕配置與分頁順序對齊，但兩套功能的動作不會完全相同。沒有在你的正式 Supabase 上執行端到端測試。
